
# Satellite Parking Lot Analysis — Retail Consumption Proxy

## Authors

- Victor Chardain

- Benoit Faivre

- Amandine Esteve

## Track

Alternative Data

## Problem

Can parking lot occupancy detected from satellite imagery predict

retail consumption indicators (Walmart stock, consumer confidence index)?

## Data

- Satellite images: Kaggle dataset (Cars Overhead With Context)

- Financial data: Yahoo Finance via yfinance

## Structure

- `code/` → Python scripts (data collection, feature extraction, model)

- `oral_presentation/` → Slides for the 7-minute presentation

- `written_presentation/` → HTML export of Jupyter notebook

## How to run

```bash

pip install -r requirements.txt

python code/main.py

```
